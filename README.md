# Lazydin

Lazydin is an automation tool for web workflows.

## Installation

```bash
pip install lazydin
```

## Usage

After installation, you can run the application with:

```bash
lazydin
```

This will start the web server on http://localhost:8000.

## Development

To set up the development environment:

```bash
# Clone the repository
git clone https://github.com/yourusername/lazydin.git
cd lazydin

# Install in development mode
pip install -e .
```
